# 罗德岛意识战术终端前端原型设计规格

## 1. 项目定义

本项目是一套以 LLM 文字交互为核心的战术角色扮演与剧情探索 Web 前端原型。原型只包含浏览器端界面、模拟数据、交互状态与本地持久化，不包含 API、数据库、鉴权、服务器、真实 LLM 请求或其他后端实现。

产品以迷迭香及其随行小队进入异常意识空间的行动为演示场景。玩家通过自然语言与战术指令推进剧情；系统同步更新意识战场、干员状态和情报档案，使叙事、战术和调查形成闭环。

### 1.1 成功标准

- 可从主作战台完整体验一次“输入指令 → 模拟流式叙事 → 感知检定 → 新线索入库 → 记忆节点解锁 → 精神负荷警告”的前端演示流程。
- 主作战台、意识战场、干员与小队、情报档案库、行动记录、系统设置均为可访问、可交互的完成态页面。
- 节点详情、拓建确认、检定详情、干员档案、情报关联、剧情回溯、快捷键、设置和高危行动确认等弹层均有完成态视觉与可操作内容。
- 界面以中文为主；品牌标记、坐标、编号和装饰性系统代码可保留英文或拉丁字符。
- 不使用 Emoji 作为图标；统一使用同一套矢量线性图标。
- 所有反馈均由应用内组件完成，不使用浏览器 `alert`、`confirm` 或外部通知。
- 关键交互在 375、768、1024、1440 像素宽度下均可用，键盘操作和减少动态效果模式可用。

## 2. 产品与体验原则

### 2.1 核心体验

玩家应感觉自己正在操作一套将医疗监测、军事调度和意识研究融合的罗德岛终端，而不是使用一个套有科幻皮肤的普通聊天应用。剧情文本保持长时间阅读舒适；战术信息在需要决策时迅速进入视线；复杂资料在次级页面中逐步展开。

### 2.2 设计原则

1. **叙事优先**：主作战台的剧情流占据最大视觉面积，战术概况不抢夺持续阅读注意力。
2. **信息有出处**：每条情报、状态变化和检定结果都能追溯到具体行动记录。
3. **风险可理解**：危险行动在确认前明确列出消耗、风险和可能后果。
4. **动效解释状态**：动画只用于表达生成、解锁、层级深入、状态升级和空间来源。
5. **深色不等于低对比**：正文、交互边界、焦点和危险信息均满足可读性要求。
6. **拖拽不是唯一方式**：意识战场和关系图均提供按钮、列表与键盘等价操作。

## 3. 信息架构

应用采用多路由战术终端结构，左侧固定主导航，顶部显示全局行动状态。大型页面按路由懒加载，页面内使用右侧检查器、底部抽屉或居中模态框承载次级任务。

### 3.1 顶层路由

| 路由 | 中文名称 | 责任 |
| --- | --- | --- |
| `/operation` | 作战主控台 | 剧情流、指令输入、当前目标与战术概况 |
| `/memory` | 意识战场 | 记忆节点、方向拓建、侦察与派遣 |
| `/operators` | 干员与小队 | 迷迭香属性、状态、装备与随行小队 |
| `/archive` | 情报档案库 | 线索、NPC、地点、事件、关系与推理台 |
| `/log` | 行动记录 | 章节、检定、抉择与状态变更时间线 |
| `/settings` | 系统设置 | 字体、密度、动效、文本速度与辅助功能 |

### 3.2 全局框架

- **跳至主内容链接**：键盘聚焦时显示。
- **左侧导航**：品牌标记、六个主路由、未读计数、当前路由指示和折叠按钮。
- **顶部状态栏**：行动代号“雨幕回声”、章节编号、模拟连接状态、全局风险等级、终端时间和快捷指令按钮。
- **主内容区**：各路由独立的语义化 `main` 内容。
- **通知中心**：右上角应用内通知堆栈，使用 `aria-live="polite"`。
- **全局弹层容器**：统一管理模态框、抽屉、确认框及焦点恢复。

## 4. 视觉系统

### 4.1 风格定位

视觉语言为“医疗档案的克制 + 战术 HUD 的锐利”。它借鉴近未来工业终端的黑白高对比、硬边网格、编号系统、清晰分隔线和磨砂浮层，但不复刻现有游戏 Logo、角色立绘或专有图形资产。

### 4.2 色彩令牌

- `background-deep`：`#07090C`，全局背景。
- `surface-primary`：`#0D1116`，正文和主要工作区。
- `surface-raised`：`#141A20`，卡片与检查器。
- `surface-glass`：`rgba(18, 25, 31, 0.78)`，导航、抽屉和模态框。
- `text-primary`：`#F4F7F8`，主文本。
- `text-secondary`：`#A9B4BC`，辅助文本。
- `line-subtle`：`rgba(184, 207, 219, 0.18)`，网格与分隔线。
- `memory-blue`：`#8ED7F7`，记忆、感知与迷迭香关联状态。
- `arts-green`：`#7EF0BD`，源石技艺、成功和有效连接。
- `warning-amber`：`#F1C875`，中高风险和待处理事项。
- `danger-red`：`#FF6B6F`，精神污染和危险操作。

功能状态必须同时使用图标、文字和边框形态，不得只依赖颜色。

### 4.3 排版

- 中文正文：`Noto Sans SC`, `Source Han Sans SC`, `Microsoft YaHei UI`, sans-serif。
- 标题与导航：同一中文字体栈，使用 600–700 字重、紧凑字距和明确层级。
- 数据、坐标与系统编号：`JetBrains Mono`, `Cascadia Mono`, monospace。
- 正文最小 16px，行高 1.65；元数据最小 12px，且不承载连续阅读内容。
- 叙事文本桌面端单行控制在约 60–75 个中文字符的可读宽度内。

### 4.4 几何与材质

- 主要容器使用 0–4px 小圆角和削角伪元素，避免消费级大圆角卡片感。
- 1px 数据分隔线、角标、坐标刻度和不对称十二列网格建立工业秩序。
- 毛玻璃只用于导航、抽屉和模态层；正文表面保持高不透明度。
- 阴影分为基础、浮层、危险三档，全部由语义令牌管理。
- 背景包含静态细网格、低对比扫描标尺和少量不可交互几何标记。

### 4.5 图标与品牌

- 统一采用 Phosphor Icons 线性风格，同层级保持相同尺寸与笔画粗细。
- 装饰图标在辅助技术树中隐藏；图标按钮必须具有可访问名称。
- 品牌文字使用原创“RHODES COGNITION TERMINAL / 罗德岛意识战术终端”，不使用现有作品 Logo 资产。

### 4.6 动效

- 快速反馈：120–160ms；普通状态变化：200–260ms；页面与大型模态进入：320–420ms。
- 进入使用减速曲线，离开时间为进入的约 65%。
- 只动画 `transform`、`opacity` 和 SVG 描边，避免动画布局尺寸。
- 重点动效包括：导航指示线滑动、LLM 流式光标、节点解锁描边、检查器来源过渡、警报等级升级和列表 30–45ms 错峰进入。
- `prefers-reduced-motion: reduce` 下关闭扫描线移动、脉冲、错峰和空间位移动画，直接呈现最终状态。

## 5. 页面设计

### 5.1 作战主控台

桌面端使用“剧情流 2fr + 战术概况 0.9fr”的双列布局。顶部为当前阶段与环境条，底部为固定但不遮挡内容的指令控制台。

#### 剧情记录类型

1. **叙事记录**：章节编号、环境描述、正文与可回溯来源。
2. **人物对白**：角色名、通讯状态和对白正文，不使用聊天气泡造型。
3. **环境扫描**：坐标、置信度、异常指标和扫描结果。
4. **检定结果**：属性、骰值、修正、难度和成功等级。
5. **系统警报**：风险原因、影响对象、恢复建议与可执行动作。

默认剧情描述小队进入被雨水淹没的废弃医疗站；迷迭香感知到墙体后存在不属于当前时间层的心智回声。每条记录提供复制、定位相关档案和打开详情的次级操作。

#### 指令控制台

- 三个输入模式：“行动描述”“战术口令”“询问队员”。
- 可见标签、输入帮助、字数状态和快捷键说明。
- 三条具体建议：“检查西侧隔离门”“让迷迭香读取残留意识”“命令小队进入防御队形”。
- 发送、暂停、继续和重新推演按钮根据生成状态显隐或禁用。
- 空输入在字段下显示“请输入行动描述，或从上方选择一项建议”，焦点保留。

#### 罗德岛战术概况

- 当前目标：确认 R-09 隔离区异常意识来源。
- 区域危险：B，精神污染缓慢上升。
- 回合顺序：迷迭香、阿米娅、未知意识体、末药、蛇屠箱。
- 小队摘要：生命、压力、行动点和异常状态。
- 三条待处理情报：护理员证词、03:17 广播、被删除的入院记录。
- 精神负荷仪表与“查看干员状态”入口。

### 5.2 意识战场／记忆回廊

#### 初始结构

表层记忆包含三个初始战术节点：

1. **雨幕中的疗养院**：危险 B，敌对意识体 3，友方锚点 1，探索度 68%。
2. **无声候车厅**：危险 C，敌情未知，可回收记忆残片 2，探索度 34%。
3. **编号 R-09 隔离室**：危险 A，精神污染持续上升，疑似关键人物投影 1，探索度 12%。

每个节点展示环境名称、层级、危险等级、敌我信息、探索进度、锚定状态和最近更新。节点之间使用 SVG 连线表达已确认路径、受污染路径和未解析路径。

#### 拓建规则

- 向下：进入深层潜意识，增加精神负荷并解锁更高价值情报。
- 向左或向右：进入未知战局，生成平行探索分支。
- 点击方向接口或使用键盘方向操作打开拓建确认框。
- 确认框显示方向、预计精神消耗、风险、推荐小队和可能收益。
- 确认后新增一个带入场动画的完成态演示节点，并更新连线、探索计数和通知。

#### 节点检查器

右侧检查器包含概况、驻守单位、环境效果、可回收情报、行动历史和进入/侦察/派遣/建立锚点按钮。危险 A 节点在进入前必须经过高危确认。

#### 等价视图

提供“战场图”和“层级列表”两个标签。列表按意识深度分组，包含与节点图相同的信息与动作，作为移动端默认视图和拖拽替代方案。

### 5.3 干员与小队

#### 迷迭香主档案

- 理智稳定度：72%。
- 精神负荷：41/100。
- 感知：16。
- 源石技艺：18。
- 意志：15。
- 战术协调：12。
- 当前状态：轻度意识重叠。
- 特性：思维感应、重力操控、记忆碎片捕获。

页面包含属性雷达式摘要的可访问文本替代、精神负荷趋势、状态效果、装备、可用能力和医疗备注。属性名可点击打开中文解释和当前修正来源。

#### 随行小队

- 阿米娅：术师，生命 86%，压力 28，行动点 2，状态“警戒”。
- 末药：医疗，生命 94%，压力 17，行动点 2，状态“药剂充足”。
- 蛇屠箱：重装，生命 78%，压力 22，行动点 1，状态“前线掩护”。

每名干员卡显示头像替代图形、职业、生命、压力、行动点、位置、状态和下一行动。点击后打开完整档案模态框，展示能力、装备、关系倾向和本局临时特征。原型不使用受版权保护的角色立绘。

### 5.4 情报档案库

#### 三种视图

1. **档案视图**：按线索、人物、地点、事件、证物分类，可搜索、筛选、排序和钉选。
2. **关系视图**：以可交互关联图展示人物、事件和证物；提供列表替代。
3. **推理台**：组合已钉选档案形成假设，分别显示支持证据、冲突证据和综合可信度。

#### 档案字段

- 唯一编号、标题、类型和状态。
- LLM 生成摘要与原始剧情来源。
- 首次发现章节、时间和发现者。
- 情报可信度、污染风险与验证状态。
- 相关人物、地点、事件和证物。
- 玩家批注、关键标记和最近更新时间。

#### 初始档案

- 线索“潮湿的儿童病历”：可信度 82%，与 R-09 入院记录冲突。
- NPC“没有倒影的护理员伊莲”：可信度 43%，身份未验证。
- 事件“凌晨 03:17 的广播录音”：可信度 76%，声音来源与建筑记录不符。
- 证物“被删除的 R-09 入院记录”：可信度 91%，存在人工覆盖痕迹。

系统主动标记时间冲突和证词矛盾，但不替玩家给出最终结论。点击原始来源可跳转行动记录并高亮对应段落。

### 5.5 行动记录

按时间展示章节、玩家指令、检定、状态变化、节点解锁和情报入库。支持按记录类型、角色和章节筛选；点击记录可打开剧情回溯模态框，并提供跳转到相关干员、节点或档案的链接。分支比较以两个并列摘要展示已采用行动和被放弃推演，不创建真实多时间线后端。

### 5.6 系统设置

- 界面密度：舒展、标准、紧凑。
- 剧情文本速度：立即、标准、沉浸。
- 动效：完整、减少、跟随系统。
- 字体大小：标准、大、特大。
- 高对比模式开关。
- 自动保存演示进度开关。
- 快捷键说明和“恢复演示初始状态”危险操作。

## 6. 模态框、抽屉与应用内反馈

### 6.1 完整弹层清单

- 节点详情检查器。
- 方向拓建确认框。
- 高危节点进入确认框。
- 检定详情模态框。
- 干员完整档案模态框。
- 情报详情与关联编辑模态框。
- 未保存批注确认框。
- 剧情回溯模态框。
- 快捷键模态框。
- 设置抽屉。
- 重置演示确认框。

所有模态框包含明确标题、关闭按钮、取消路径和主操作；打开时聚焦标题或首个合理控件，焦点被限制在弹层内，Escape 关闭非强制流程，关闭后焦点返回触发元素。

### 6.2 通知类型

- 成功：节点已建立、情报已关联、批注已保存。
- 警告：精神负荷上升、情报存在冲突、路径尚未锚定。
- 危险：污染阈值接近、进入高危节点、重置演示。
- 处理中：正在解析指令、正在重建记忆路径。

通知支持关闭；可恢复操作提供撤销按钮；失败状态提供重试或跳转处理。通知不抢夺键盘焦点。

## 7. 前端状态与数据流

### 7.1 状态领域

- `session`：行动代号、章节、阶段、目标、模拟连接和全局风险。
- `narrative`：记录、输入模式、草稿、建议动作、生成状态、检定和错误。
- `memoryMap`：节点、连线、视口、选中项、视图模式和拓建结果。
- `operators`：属性、生命、压力、行动点、状态、装备和队形。
- `archive`：档案、关联、筛选、钉选、假设和批注草稿。
- `ui`：导航、弹层、通知、密度、动效、字体和高对比偏好。

各页面只订阅所需领域；路由切换保留筛选、草稿与滚动位置。演示进度和界面偏好可序列化至 `localStorage`，读取失败时回退到内置初始数据。

### 7.2 NarrativeEngine 接口

前端定义可替换的叙事引擎接口，原型只提供本地模拟实现。模拟实现根据预置指令产生分段文本、检定结果、状态更新和新档案，并支持暂停、继续、取消和重试。接口边界不发起网络请求，也不包含任何服务端密钥或配置。

### 7.3 演示闭环

1. 玩家选择建议“让迷迭香读取残留意识”。
2. 系统显示“正在解析战术意图”，随后流式输出记忆片段。
3. 触发感知检定，展示骰值、修正、难度和成功结果。
4. 情报库新增“墙体后的儿童合唱”线索并显示未读计数。
5. 意识战场解锁 R-09 下方的深层入口。
6. 迷迭香精神负荷从 41 上升至 57。
7. 顶部出现应用内警告，并提供“查看状态”动作。

## 8. 错误与风险处理

- 空指令：字段下方显示具体错误并保留焦点。
- 模拟生成中断：剧情流中插入中断记录，提供继续和重新推演。
- 高危行动：确认框列出精神消耗、风险与可能后果。
- 精神负荷过高：顶部警报、属性卡和行动按钮同时呈现状态。
- 未保存批注：关闭前提供保存、放弃和继续编辑。
- 本地数据解析失败：显示故障面板并提供恢复初始数据。
- 删除关联或重置演示：二次确认，完成后提供可撤销通知；重置操作不提供撤销，但确认文案明确影响范围。

## 9. 响应式设计

- **1440px 及以上**：展开侧栏、双列作战台、常驻右侧概况。
- **1024–1439px**：压缩侧栏，概况可折叠，档案关系图减少非关键标签。
- **768–1023px**：单列主内容，次级信息进入底部抽屉，导航保持可见。
- **375–767px**：顶部紧凑导航，剧情与指令优先，意识战场默认层级列表，关系图默认列表。

固定导航、状态栏和指令控制台必须为滚动内容预留空间，任何断点不得出现页面级水平滚动。

## 10. 可访问性

- 使用 `header`、`nav`、`main`、`section`、`article`、`aside`、`form`、`dialog` 等语义化元素。
- 标题按顺序组织，不跳级。
- 所有可交互元素具有唯一、描述性 ID；命名采用 `区域-对象-动作` 结构，例如 `operation-command-submit`。
- 图标按钮具有可访问名称，装饰图标设置 `aria-hidden="true"`。
- 所有字段有可见标签和关联错误说明。
- 模态框具有焦点锁定、Escape 路径和触发点焦点恢复。
- 键盘焦点环在深色与高对比模式下均清晰可见，且不被固定元素遮挡。
- 节点图和关系图提供列表替代、按钮操作和键盘操作。
- 状态更新通过单一、上下文完整的 `aria-live` 区域播报。
- 正常正文对比度至少 4.5:1，图形控制边界至少 3:1。
- 减少动态效果模式保留状态变化，但移除不必要运动。

## 11. 性能策略

- React 路由和意识战场、关系图等重组件使用 `lazy` 分割。
- 毛玻璃只应用于有限浮层，避免大面积持续合成。
- 高频输入与视口变化使用节流或防抖；状态更新按领域拆分，避免全树重渲染。
- 仅动画合成友好的属性，避免布局抖动和累积布局偏移。
- 静态图标使用树摇友好的独立导入。
- 不从远程加载首屏关键字体；使用本地字体栈。
- 原型档案数量保持在 50 条以下，但档案列表组件保留未来虚拟化边界。
- 所有异步模拟区域预留稳定尺寸，流式生成不推动固定控制区跳动。

## 12. 测试与验收

### 12.1 自动化行为测试

- 六个顶层路由均可访问，当前导航状态正确，返回后保留筛选与草稿。
- 指令模式切换、建议填入、发送、流式模拟、暂停、继续和重试正常。
- 空输入显示内联错误且不调用浏览器原生弹窗。
- 三个初始记忆节点显示正确，向下、向左、向右均可拓建。
- 节点详情、检定详情、干员档案、情报关联和设置弹层可开关。
- 高危确认、精神负荷警告、未保存批注和重置确认正常。
- 完成演示指令后，线索、节点、精神负荷和通知同步更新。
- Escape、Tab 焦点循环、焦点恢复和列表替代视图正常。
- 减少动态效果偏好禁用非必要动画。
- 交互元素 ID 在文档中唯一。

### 12.2 浏览器视觉验收

- 检查 375、768、1024、1440 像素宽度及小屏横向布局。
- 检查主作战台、意识战场、干员页、情报库三种视图和全部关键弹层。
- 检查叙事长文本可读性、模态背景隔离、焦点可见性和危险状态辨识度。
- 检查悬停、按压、流式生成、节点解锁和警报动效无布局跳动。
- 检查浏览器控制台无错误或警告。
- 检查首次构建输出、路由分包和资源体积，确认无非必要大型依赖。

## 13. 明确不在范围内

- 真实 LLM、联网请求、API 密钥和提示词服务。
- 数据库、账户、云同步、多人协作和权限系统。
- 服务器端游戏规则、反作弊、存档服务和部署基础设施。
- 角色立绘、现有游戏 Logo、原作音频或其他受版权保护的媒体资产。
- 完整战斗数值平衡和可无限生成的实际剧情内容。

本规格的交付物是可在本地运行、视觉完成、交互充分且便于未来接入真实 LLM 的纯前端高保真原型。
