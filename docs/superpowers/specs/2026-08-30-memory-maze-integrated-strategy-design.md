# 《迷迭香的记忆迷宫》B+C 混合玩法初版设计

日期：2026-08-30

## 目标

在仅以迷迭香为主角的前提下，将现有单层节点演示扩展为可重复游玩的三层肉鸽流程。初版必须同时包含战斗、休息处、商店、奇境、未知和 Boss 房六类节点，并让路线、局内货币、认知模块、记忆碎片、过载度与四柄巨剑共同影响决策。

本地规则引擎始终拥有地图、概率、数值和奖励的最终权威。LLM 只生成符合既有节点与结果的叙事、事件文案和临时台词，不得改变本地结算。

## 初版边界

- 单局固定三层，每层生成 8 至 11 个节点。
- 第一层从休息处开始，第三层以唯一 Boss 房结束。
- 单局全局保证六类节点至少各出现一次；每层至少包含战斗、休息处和一种非战斗节点。
- 不加入其他可操作角色，不实现招募、编队或职业系统。
- 不实现跨局天赋树；仅保留现有首次通关、无尽模式和小说模式解锁。
- 不依赖外部图片或音乐才能游玩；缺失资源时使用项目内占位资源与文本回退。

## 核心循环

1. 玩家在迷宫图上查看已知节点、未知节点和可达路径。
2. 玩家可以消耗巨剑的本层探索充能，侦测、破壁、防护或共鸣。
3. 玩家选择下一节点并进入对应的独立交互面板。
4. 节点结算改变稳定性、过载、记忆残响、认知模块、碎片或路线状态。
5. 当前节点完成后开放后继路径；层末进入下一层，最终击败 Boss 后通关。
6. 失败条件仍为稳定性降至 0 或过载达到 100%。

## 节点体系

### 战斗 `combat`

- 具有敌方完整度、威胁等级和两至三轮战斗进度。
- 玩家使用四柄巨剑的现有战术动作削减敌方完整度、建立防护或取得洞察。
- 普通胜利奖励记忆残响，并从碎片、恢复和认知模块中提供一次奖励选择。
- 高危战斗由节点修饰词标记，敌人更强但模块掉落率更高。

### 休息处 `rest`

玩家只能选择一种休整方案：

- 神经校准：恢复稳定性。
- 降载静默：降低过载。
- 武装维护：恢复一项巨剑探索充能并缩短战术冷却。

### 商店 `shop`

- 使用局内货币“记忆残响”。
- 商品池包含恢复耗材、侦测点、碎片槽扩容和认知模块。
- 商品价格由层数与稀有度决定；购买后立即结算。
- 商店允许一次“回收记忆”，玩家放弃普通碎片换取残响，核心碎片不可出售。

### 奇境 `wonder`

- 显示明确标题和风险描述，提供二至三个本地规则选项。
- 部分选项要求特定碎片标签或共鸣状态，记忆碎片由此成为事件钥匙。
- 奇境可创建延迟效果，例如下一场战斗增益、商店折扣或 Boss 修饰词变化。
- LLM 启用时可以改写场景与台词，但必须使用本地提供的选项标识和效果。

### 未知 `unknown`

- 地图创建时已经确定隐藏结果，进入前只显示风险等级，不临时重掷。
- 隐藏结果可为战斗、奇境、商店、休息处或认知陷阱。
- 感知巨剑可以揭示一个可达未知节点；高过载会提高战斗与陷阱权重。
- 未侦测直接进入时给予少量额外残响，形成风险补偿。

### Boss 房 `boss`

- 第三层唯一终点，使用两阶段本地规则。
- 第一阶段要求削减核心防护；第二阶段要求提升核心稳定度。
- 过载达到 70% 时启用额外故障修饰；持有指定碎片标签或模块可以解锁反制选项。
- 胜利获得核心碎片并结束 Run。

## 局内资源与构筑

### 记忆残响

战斗、冒险选项与高风险未知节点产出，商店与部分奇境消耗。Run 结束后清零。

### 侦测点

用于查看可达未知节点的真实类型和风险。感知巨剑也能完成侦测，因此侦测点是替代手段而非强制资源。

### 认知模块

初版提供八个确定性模块，分为普通、稀有两档。模块通过战斗奖励、商店和奇境获得，同名模块不叠加。

- 破壁回路：破壁巨剑伤害提高。
- 守望棱镜：进入战斗时获得防护。
- 感知阵列：每层首次侦测不消耗资源。
- 共鸣导线：核心稳定效果提高。
- 降载滤波器：节点移动时少量降低过载。
- 记忆缓存：普通碎片槽位增加一格。
- 残响回收器：战斗获得额外残响。
- 白噪声协议：未知陷阱的负面效果降低。

### 碎片事件钥匙

普通碎片继续占用有限槽位，同时通过标签解锁奇境、商店和 Boss 的特殊选项。强制遗忘由此成为构筑取舍，而不只是容量惩罚。

## 四柄巨剑的地图能力

每柄巨剑每层获得一次探索充能，进入下一层时恢复。探索能力与原有战术冷却分开记录。

- 破壁：开启一条被封锁的替代路径。
- 守望：为下一节点添加防护标记，降低第一次负面结算。
- 感知：揭示一个可达未知节点的真实类型和风险。
- 共鸣：激活当前奇境或 Boss 中需要记忆共鸣的特殊选项。

## 地图生成

地图生成器按深度列创建有向无环图，而不是先生成线性链再随机跨接。

- 每层包含起点列、三至五个中间列和出口列。
- 中间列生成一至三个节点，并确保每个节点至少有一条入边和一条可继续前进的出边。
- 第一层起点为休息处，前两层出口为层间通道，第三层出口为 Boss。
- 节点分配采用带约束的权重抽样，先满足全局必需类型，再填充随机类型。
- 未知节点保存 `hiddenType`，地图 UI 只在侦测或进入后公开。
- 生成后验证唯一 ID、可达性、Boss 唯一性、节点类型配额和无环性；失败时使用同一随机状态确定性重试。

## 状态模型

`RoguelikeState` 增加：

- `run.floor` 与 `run.maxFloor`。
- `economy.echoes`、`economy.scoutPoints`。
- `modules` 模块列表。
- `explorationCharges` 四柄巨剑本层充能。
- `pendingEncounter` 当前节点交互与结算状态。
- `routeEffects` 下一节点防护、商店折扣和 Boss 修饰等延迟效果。

`MazeNode` 增加风险、隐藏类型、修饰词、结算状态与可选资源引用。旧存档通过迁移创建默认经济、模块和探索充能；无法恢复的旧进行中 Run 重建为同种子第一层，但保留图鉴与通关进度。

## 交互界面

### 意识战场

- 六类节点使用不同矢量图标、轮廓与文本标签，不用颜色作为唯一识别方式。
- 未知节点显示风险等级；侦测后显示真实类型。
- 可达节点支持侦测、破壁和进入操作；节点详情明确展示可能收益与风险。
- 列表模式与拓扑模式提供相同能力。

### 作战主控台

- 现有通用“完成节点”面板替换为按节点类型分发的交互面板。
- 顶部状态栏增加层数、残响、侦测点和模块数量。
- 战斗、休息、商店、奇境、未知揭示与 Boss 均有独立面板，但统一通过本地 `resolveEncounter` 入口结算。
- 节点未完成时不能移动；完成后地图开放后继节点。

## 外部资源占位约定

项目根目录 `assets` 是可替换外部资源目录，初版建立以下结构：

- `assets/images/characters/`：头像、半身像、立绘。
- `assets/images/nodes/`：六类节点背景和事件插图。
- `assets/images/modules/`：认知模块插图。
- `assets/audio/bgm/`：地图、战斗、Boss 音乐。
- `assets/audio/sfx/`：按钮、节点、战斗和结算音效。
- `assets/placeholders/`：空白角色图、通用节点图、通用模块图。

`src/assets/assetRegistry.ts` 作为唯一引用入口。图片资源缺失时返回对应 SVG 占位图；音频资源缺失时不创建播放器实例，并向界面返回“资源待填充”状态。业务组件不得直接拼接文件路径。`assets/README.md` 记录建议文件名、格式和替换方法。

## LLM 边界

- 小说模式仍由本地地图先生成拓扑和节点类型，LLM 只能补充标题、描述与主题。
- 奇境请求只允许返回本地选项 ID 对应的叙事文本，不接受数值、奖励或新路径。
- 未知节点的隐藏结果在请求前已经确定，LLM 不得选择节点类型。
- 所有 LLM 输出继续经过结构校验；失败时使用离线文案，不阻塞结算。

## 错误处理

- 无效购买、重复模块、资源不足、非法路径和重复结算返回明确拒绝原因且不修改状态。
- 地图验证失败不会进入 UI；同种子重试仍失败时回退到内置安全模板。
- 占位图片加载失败时显示 CSS 结构占位，不出现破图图标。
- 音频文件缺失或浏览器拒绝自动播放时保持静音，不影响游戏操作。

## 测试与验收

- 单元测试覆盖六类节点生成配额、同种子确定性、地图可达性和隐藏类型权重。
- 规则测试覆盖商店购买、休息选择、战斗奖励、奇境钥匙、未知侦测、巨剑地图能力和两阶段 Boss。
- 状态迁移测试覆盖旧存档默认值与进行中 Run 重建。
- 组件测试覆盖每类节点面板的操作、禁用条件与文本回退。
- E2E 完成一局三层预设模式，至少经历战斗、休息、商店、奇境、未知和 Boss。
- 375、768、1024、1440 视口无页面级横向溢出；键盘可以完成地图选择和节点结算。
- 构建产物在没有任何正式图片或音频文件时仍能完整游玩。
