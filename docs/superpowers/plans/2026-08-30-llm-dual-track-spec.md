# 《迷迭香的记忆迷宫》LLM 双轨驱动规格

## 目标

在已经可完整离线通关的单主角肉鸽上增加三项可选能力：进入空白断层时生成独立事件；小说剧情模式为本地生成的迷宫提供主题、节点叙事和通关剧情；每次关键迷宫行动后生成不超过 30 个汉字的迷迭香第一人称临时台词。

## 行为边界

- 未配置 API 时，预设模式和本地无尽保持完整可玩，不出现失败请求或被禁用的核心玩法。
- 小说剧情模式仅在首次通关且 API 已配置时可选择。
- LLM 只生成文本和语义意图；本地种子规则唯一决定拓扑、随机触发、判定阈值、数值效果、奖励和胜负。
- 独立事件固定包含标题、情境和 2–3 个选择；选择只携带受控的语义意图枚举。
- 小说蓝图必须与本地迷宫节点数一致，节点类型来自本地迷宫，模型不得新增、删除或重连节点。
- 临时台词必须为迷迭香第一人称、单句且不超过 30 个汉字；不合法响应使用本地台词回退。
- 所有人物头像和立绘继续只使用 `public/assets/characters/blank-character.svg`。
- API 密钥只从现有 IndexedDB 设置读取，不写入日志、通知、游戏状态或导出数据。

## 失败策略

- 网络失败、超时、取消、非 JSON、字段缺失和越界内容均转为可识别错误，不写入半成品状态。
- 独立事件失败时使用确定性离线事件池；小说蓝图失败时保留本地拓扑并使用离线主题；台词失败时使用本地短句。
- UI 必须明确显示“远程生成”“本地回退”或“离线预设”，不得把回退内容伪装成模型结果。

## 验收

- 同一 Seed 和相同本地状态产生相同的触发时机、判定、数值、拓扑和回退内容。
- 接入可控假传输层后，三类 Prompt 均可得到经过运行时校验的结构化结果。
- 正常界面可自动触发 AI 事件、选择事件分支、显示临时台词，并在小说模式显示完整主题迷宫叙事。
- 断网或模型返回畸形内容时，当前 Run 继续可玩且产生明确通知。
