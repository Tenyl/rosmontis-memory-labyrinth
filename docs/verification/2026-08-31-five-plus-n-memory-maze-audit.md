# 5+N 层《迷迭香的记忆迷宫》验收审计

日期：2026-08-31  
分支：`codex/rosemary-memory-maze`  
范围：五层离线玩法闭环、第六层及以后 LLM 扩展、陪伴与记忆系统、PRTS 视觉统一、异常回退和回归测试。

## 结论

本轮清单已经实现为一套由本地规则掌握数值权威、LLM 只提供结构化叙事的 5+N 层单主角肉鸽。离线模式可完整通过 1—5 层；配置兼容接口后可从第五层胜利界面进入第六层“无垠心海”；网络或结构异常会回退到本地蓝图，不会改写迷宫拓扑、数值或 Run 进度。

## 关键端到端场景

- `e2e/five-floor-offline.spec.ts`：通过真实 UI 完成 1—5 层，逐层读取拓扑并验证八类节点，检查核心记忆、Run 历史和本地无尽解锁。
- `e2e/mindsea-llm.spec.ts`：模拟兼容 OpenAI 接口，完成第五层后进入第六层，验证“无垠心海”人格 Prompt、远程主题和本地可达拓扑。
- `e2e/llm-fallback.spec.ts`：让接口返回空节点清单和越权伤害字段，验证 Schema 拒绝、人格化告警、本地蓝图和 Run 进度保持不变。

## 运行边界

- LLM 输出仅作为叙事附注，所有节点类型、连线、检定结果、奖励、伤害、稳定性、过载和胜负始终由本地规则引擎决定。
- `assets` 中现有图片与声音为占位或待填充资源；后续替换真实素材时应保持注册键和无障碍文本不变。
- “60 fps”依赖最终素材大小和目标设备，当前交付通过减少动效偏好、CSS 合成层控制和响应式回归降低风险；加入正式大图、音频后仍应进行真机性能复测。
