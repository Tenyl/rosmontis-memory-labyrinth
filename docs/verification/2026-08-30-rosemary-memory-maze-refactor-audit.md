# 《迷迭香的记忆迷宫》重构最终验收记录

日期：2026-08-30

工作分支：`codex/rosemary-memory-maze`

对比基线：`feature/sillytavern-rhodes-integration`

环境：Windows / Node.js v24.14.0 / pnpm 11.19.0 / Chromium（Playwright 1.62.1）

## 验收结论

项目已重构为以迷迭香为唯一主角、无需 API 也可完成通关并解锁无尽模式的纯前端肉鸽游戏。核心规则、迷宫拓扑、D20 检定、四柄巨剑、记忆碎片取舍、局外图鉴与 Run 历史均由本地确定性状态机负责；可选 LLM 只提供独立事件、临时台词和小说模式主题叙事，不拥有移动、数值结算、奖励或胜负判定权。

所有人物头像与立绘统一渲染为 `public/assets/characters/blank-character.svg`，后续只需替换该项目资源即可接入正式美术。

## 规则与数据边界

- 所有随机流程由可复现 Seed 驱动；运行时代码不使用 `Math.random()`。
- LLM 输出先经过严格结构校验，再映射为本地允许的效果；它不能改写拓扑、移动合法性、数值、奖励或胜负。
- 请求异常只暴露固定中文错误，不回显响应正文或 API Key。
- API Key 存放于浏览器 IndexedDB；游戏 localStorage 状态不包含接口设置。
- 完整备份会清空主、次 API Key；通知、规则日志和状态摘要不记录密钥。
- 本项目仍是纯前端浏览器直连，远程端点需要允许 CORS；没有把该模式描述为服务端密钥保护方案。
