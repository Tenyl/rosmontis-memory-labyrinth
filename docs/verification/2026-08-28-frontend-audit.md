## 4. 十一类弹层与次级交互面

1. 节点详情检查器：环境、敌我、效应、情报、探索度与路径操作完整。
2. 方向拓建确认：起点、预估节点、方向、风险、精神负荷与确认路径完整。
3. 高危节点确认：危险说明、保持当前位置与确认进入完整。
4. 检定详情：投掷、修正、难度、成功余量与后果完整。
5. 干员完整档案：生命、负荷、能力、装备、关系与临时特征完整。
6. 情报详情／批注：来源、发现者、可信度、污染、关联与玩家批注完整。
7. 未保存批注确认：继续编辑、放弃更改、保存并关闭三条路径完整。
8. 剧情回溯：原始文本、检定、来源编号与相关页面跳转完整。
9. 快捷键说明：`?`、`/`、`Ctrl/Cmd + Enter`、`Tab`、`Escape` 完整。
10. 设置工作区：六类偏好即时生效，文本速度与自动保存具有真实本地行为。
11. 重置演示确认：影响范围、取消与确认恢复完整。

Playwright 验证了快捷键、拓建、高危进入、干员档案、档案嵌套弹层、剧情回溯和重置确认的 Escape 路径与焦点恢复。通用 `Dialog` 提供焦点锁定，并在嵌套弹层同时卸载时跳过已断开的触发元素。

## 6. 验收中发现并修复的问题

| 问题 | 根因 | 修复与回归证据 |
|---|---|---|
| 4173 端口无法绑定 | Windows 将该端口纳入保留范围 | Playwright 固定改用 4317；33 项通过 |
| 迷迭香负荷无法按 meter 查询 | 环形监测缺少量表语义 | 增加 `role="meter"` 与 ARIA 数值；组件和核心闭环通过 |
| 嵌套档案弹层焦点丢失 | 不稳定关闭回调反复覆盖原触发器，且内层触发器同时卸载 | 稳定回调 ref、微任务恢复且检查 `isConnected`；嵌套弹层 E2E 通过 |
| 375px 意识战场多出 4px | 汇总条负边距仍使用 16px，而页面边距为 12px | 420px 专用边距对齐；四档 `/memory` E2E 通过 |
| 直接进入非主控台时通用按钮退化 | `.terminal-button` 误置于作战页懒加载 CSS | 迁入共享组件 CSS并添加契约测试 |
| 直接进入行动记录时辅助标签可见 | `.sr-only` 误置于档案页懒加载 CSS | 迁入全局 CSS并添加契约测试 |
| 移动端横向滚动条过重 | Windows 默认滚动条与终端视觉冲突 | 全局统一 6px 细轨道与状态色悬停 |
| `pnpm test` 收集 E2E 文件 | Vitest 未限定测试目录 | 限定 `src/**/*.test.{ts,tsx}`；45 项全绿 |
