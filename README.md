# 罗德岛意识战术终端

面向 LLM 文字跑团与战术角色扮演的纯前端原型。项目以原创的罗德岛式医疗／军事终端语言组织剧情文本流、战术指令、意识战场、干员状态、情报档案与行动追溯；不包含后端、远程模型调用或外部数据传输。

## 页面与能力

- `/operation`：剧情文本流、三种指令模式、建议行动、本地分段叙事、暂停／继续、检定详情与罗德岛战术概况。
- `/memory`：三个表层记忆节点、拓扑图／战术列表、节点检查器，以及向左、向右、向下拓建路径。
- `/operators`：迷迭香理智、精神负荷、跑团属性、源石技艺、装备和三名随行干员档案。
- `/archive`：线索、NPC、事件与证物档案；支持搜索、筛选、钉选、玩家批注、关系图和证据推理台。
- `/log`：章节、指令、检定、状态变化、节点解锁和情报入库的不可变时间线与剧情回溯。
- `/settings`：密度、文本速度、动效、字号、高对比、自动保存、快捷键说明和演示状态恢复。

所有状态均由浏览器端演示数据和 `localStorage` 驱动。提交“让迷迭香读取残留意识”可体验从剧情生成到精神负荷、记忆节点、情报档案和行动记录同步更新的完整闭环。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建与预览：

```bash
pnpm build
pnpm preview
```

## 验证

```bash
pnpm test
pnpm test:e2e
pnpm typecheck
pnpm build
```
