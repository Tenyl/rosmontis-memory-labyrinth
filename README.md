# 罗德岛意识战术终端

面向 LLM 文字跑团与战术角色扮演的纯前端原型。界面采用原创的医疗档案与军事终端语言，整合剧情文本流、意识战场、干员状态、情报档案、行动追溯和 SillyTavern 兼容的角色／世界书／预设管理。

项目不包含后端、账号系统或服务器数据同步。默认使用可离线体验的本地模拟模型；配置 API Key 后，也可由浏览器直接调用 OpenAI 兼容端点。

## 核心体验

- `/operation`：真实酒馆运行时驱动的剧情文本流、思考折叠、选项快捷键、三种指令模式、停止／重试、历史编辑重生成与来源分支。
- `/memory`：三个表层记忆节点、拓扑图／战术列表、节点检查器，以及向左、向右、向下拓建意识路径。
- `/operators`：迷迭香的理智、精神负荷、感知、源石技艺、装备与三名随行干员档案。
- `/archive`：LLM 回合产生的线索、NPC、地点、事件与证物；支持搜索、筛选、钉选、批注、关系图、证据推理与来源回跳。
- `/log`：可载入、重命名、分支、导出和删除的会话树，以及章节、检定、状态变化和情报入库时间线。
- `/settings`：接口连接、生成预设、六标签解析协议、本地数据、视觉与无障碍五个设置工作区。

全局“酒馆编排中枢”提供以下中文化管理界面：

- 会话：新建、切换、重命名、删除、从任意会话末尾分支。
- 变量：按当前会话编辑键值并持久化。
- 角色与身份：SillyTavern V2 角色卡导入／导出、角色编辑器与独立玩家身份。
- 世界书：批量导入／导出、主次关键词、选择逻辑、常驻、递归、概率、注入位置、深度和高级扫描参数。
- 预设：SillyTavern/OpenAI 预设导入／导出、采样参数、提示词文本与注入顺序编辑。

## LLM 运行链

每次行动会经过同一条前端运行链：

1. 从当前角色、玩家身份、预设、历史、变量与启用的世界书装配 Prompt。
2. 扫描世界书关键词，并记录命中的条目来源。
3. 选择本地模拟或浏览器直连的 OpenAI 兼容流式适配器。
4. 增量解析 `<thinking>`、`<maintext>`、`<option>`、`<sum>` 与 `<vars>` 标签；无法解析时回退为纯文本。
5. 持久化消息与变量快照，并投影到意识节点、干员状态、档案和行动记录。

本地模拟会在界面中明确标为“本地模拟”，不会伪装成远程模型连接。

## 数据与安全边界

- 酒馆角色、身份、世界书、预设、会话、消息、变量与接口设置保存在浏览器 `IndexedDB`（数据库版本 V4）。
- 战术投影与界面偏好保存在 `localStorage`。
- 完整备份包含酒馆内容与会话，但会主动移除主／次 API Key。
- 本项目没有后端代理。远程接口必须允许浏览器跨域请求；在共享设备上保存浏览器端密钥前，请自行评估风险。
- “恢复战术演示”不会删除酒馆数据库；清理会话和恢复酒馆默认内容均使用应用内确认框。

## 本地运行

需要 Node.js 与 pnpm：

```bash
pnpm install
pnpm dev
```

生产构建与预览：

```bash
pnpm build
pnpm preview
```

pnpm build
